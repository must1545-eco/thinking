# 날짜·나이 계산기 (date-age-site)

생년월일 하나로 **만 나이·연 나이·띠·별자리·다음 생일 D-day·태어난 지 며칠째**를 계산하고,
**날짜 차이(D-day)** 와 **날짜 더하기·빼기(주말 제외)** 까지 한 페이지에서 처리하는 정적 웹사이트입니다.

- 파일: `index.html` **단일 파일** (HTML + CSS + JS 내장, 빌드 과정 없음)
- 개인정보처리방침: `privacy.html` (같은 디자인 토큰의 정적 문서, 푸터에서 링크)
- 외부 요청 없음: 폰트·CDN·이미지를 불러오지 않아 오프라인에서도 그대로 동작합니다.
- 입력값은 서버로 전송되지 않습니다. 모든 계산은 방문자 브라우저 안에서만 이루어집니다.

## 기능

| 탭 | 내용 |
| --- | --- |
| 나이 계산 | 만 나이(큰 카드), 만 나이 상세(년·개월·일), 연 나이, 띠(간지), 별자리, 다음 생일 D-day, 태어난 지 N일째, 태어난 요일 |
| 날짜 차이 | 두 날짜 사이 일수, 초일 포함/순수 일수 토글, 오늘 기준 D-N·D-Day·D+N, 주·개월·년 환산 |
| 날짜 더하기 | N일·N주·N개월·N년 후/전, 100·200·300·1000일 빠른 버튼, 주말(토·일) 제외 평일 계산(공휴일 미포함 명시) |

## 계산 규칙

- **만 나이**: 「행정기본법」 만 나이 통일(2023. 6. 28. 시행) 기준. 생일이 지나지 않았으면 1살을 뺍니다.
- **2월 29일생**: 2월 29일이 없는 해에는 2월 28일에 생일이 온 것으로 봅니다(민법 제160조 제3항).
- **띠**: 음력 정월 초하루(설날) 기준. 1900~2050년 설날 양력 날짜를 파일 안에 내장했고, 그 밖의 연도는 양력 연도 기준입니다.
- **날짜 연산**: `Date` 문자열 파싱(UTC 오차)을 쓰지 않고 연·월·일 정수와 UTC 일련번호로만 계산합니다. 서머타임·시간대의 영향을 받지 않습니다.
- **개월 더하기**: 1월 31일 + 1개월 → 2월 말일(28일/29일)로 보정합니다.
- **주말 제외**: 토·일만 제외하며 공휴일·임시공휴일은 포함합니다.

## 로컬에서 보기

`index.html` 을 브라우저로 열면 바로 동작합니다. (별도 서버 불필요)

## GitHub Pages 배포

공개 주소: **https://must1545-eco.github.io/thinking/** (저장소 `must1545-eco/thinking`, 소스 `main` / `/ (root)`)

1. 이 폴더의 `index.html` `privacy.html` `robots.txt` `sitemap.xml` 을 `main` 브랜치 루트에 올립니다.
2. 저장소 **Settings → Pages** 에서 Source를 `Deploy from a branch`, Branch를 `main` / `/ (root)` 로 지정합니다.
3. 잠시 뒤 `https://must1545-eco.github.io/thinking/` 에서 열립니다.
4. 검색 노출용 `robots.txt`·`sitemap.xml` 은 저장소에 포함되어 있고, 안의 주소는 위 공개 주소 기준입니다. `og:image` 는 아직 없습니다(`og:url`·`canonical` 은 반영 완료).
